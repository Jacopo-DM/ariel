Morphological measures of a built robot.

The counts come from the graph the robot was built from (CoreModule.graph, see MorphologicalCounts); the size measures from its geoms at joint angle zero, in metres, along the core’s own axes: depth from FRONT to BACK, width from LEFT to RIGHT, height from TOP to BOTTOM. This class adds the proportions and the single-letter aliases.

Symmetry, per plane through the centre of the core: a module is on the plane when its centre (the volume-weighted centre of its geoms) is within half its thinnest side of it; an off-plane module is mirrored when a module of the same type sits at its mirror point, within half the thinner of the two thinnest sides. The score is the share of off-plane modules that are mirrored, 0.0 when no module is off the plane.

Parameters:

robot (CoreModule) – A robot from construct_mjspec_from_graph or a prebuilt builder.

construct_mjspec_from_graph(graph: networkx.DiGraph[int], *, repair_overlaps: bool = False) → ariel.body_phenotypes.robogen_lite.modules.core.CoreModule¶

Construct a MuJoCo specification from a graph representation.

Can be used for constructing the body of a robot after crossover using the graph representation.

Parameters:

  • graph (Graph) – A graph representation of the robot’s structure.

  • repair_overlaps (bool) – When True, modules that sit inside each other are pruned first (the deeper module of an overlapping pair goes, with everything attached beyond it) and the body is built from the pruned copy; the graph itself is not changed. See the overlap module of this package.

Returns:

The core module of the robot, which contains all other modules; an unknown module type raises ValueError.

Return type:

CoreModule

  • core (CoreModule) – The body built from graph.

repair_overlaps(graph: Graph, build: Builder) → Graph¶

Prune modules until no two modules overlap beyond the tolerance.

Each round builds the body, finds the overlapping pairs, and removes the later module of the pair whose later module is deepest (ties: the smaller node id), with its subtree; removing the deepest first keeps the most of the body. Every round removes at least one module, so the loop ends.

Parameters:

  • graph (nx.DiGraph[int]) – The robot graph; it is not changed.

  • build (Callable) – Builds the body of a graph, for example the constructor.

Returns:

A copy of the graph without overlaps; the graph itself when there were none.

Return type:

nx.DiGraph[int]

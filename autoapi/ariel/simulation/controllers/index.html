set_control(model: mujoco.MjModel, data: mujoco.MjData, *args: object, **kwargs: object) → None¶

Set the controller callback function and gives additional arguments.

Parameters:

  • model (mj.MjModel) – The Mujoco model of the simulation. This will be used to access model parameters, such as the number of actuators.

  • data (mj.MjData) – The Mujoco data of the simulation. This will be used to access simulation variables, such as the current time and control values.

  • *args (object) – Additional arguments to pass to the controller callback function.

  • **kwargs (object) – Additional keyword arguments to pass to the controller callback function.

Raises:

ValueError – If the control signal contains NaN.

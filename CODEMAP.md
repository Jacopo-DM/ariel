## Entry points

- Package `ariel` (`src/ariel/__init__.py`): exports `DATA`, `SEED`, `RNG`, `console`, `log`; first reads `mujoco_user_config.json` to set `MUJOCO_GL` (before anything imports mujoco).
- `python -m ariel.opengl.gl_manager`: probes the OpenGL backends and writes `mujoco_user_config.json` in the current folder.
- `python tools/measure_structure.py`: prints size, import-count and entry-point numbers for `src/ariel` and `tests` (`tools/` is not a package; its test is `tests/unit/test_tools/`).
- `python tools/run_notebooks.py [FILE ...] [--slow] [--timeout S] [--save]`: runs the notebooks of `tests/functional` from a clean kernel and prints PASS, FAIL or SKIP for each (`tests/unit/test_tools/test_run_notebooks.py`); `python tools/render_floors.py`: renders one picture per world; `python tools/measure_overlap.py`: counts bodies with overlapping modules (`tests/unit/test_tools/test_measure_overlap.py`). `python tools/benchmark.py`: times the four workloads of the speed-up goal, each run in a fresh process (`tests/unit/test_tools/test_benchmark.py`).
- `python tools/compile_terrains.py`: builds every world class and stores its XML in `src/ariel/simulation/environments/pre_compiled/`, the cache that `load_precompiled=True` reads.
- `examples/parallel_robot_eval.py`: subclasses `MuJoCoWorkerBase` for a targeted-locomotion task with a CMA-ES-optimised ANN controller and evaluates robots in a spawned process pool.
- `tools/robot_builder.html`: a browser editor (three.js 0.164.1 from cdn.jsdelivr.net) to build a body by clicking and export it as a table of parts for `prebuilt_robots.parts.build`; its sizes and attachment frames copy the modules in `robogen_lite/modules/`.
- `examples/`: runnable scripts (`a_mujoco`, `b_robots`, `c_genotypes` (includes `cppn_genome_checks.py`, the old `cppn_neat/tests.py`), `re_book`, `z_ec_course`, `new_EC_engine_example.py`).
- `tests/unit/` mirrors `src/ariel/`; `tests/functional/` is the functional notebooks, one per feature area, with the table of areas in its `README.md` (`tests/unit/test_functional_notebooks.py` checks the table against `src/ariel`); `tests/conftest.py` presets `MUJOCO_GL`; `tests/unit/test_wiki_structure.py` checks the knowledge wiki in `.claude/wiki/` (not `src`).
- `.claude/wiki/`: knowledge wiki in topic folders `mujoco/`, `mjx/`, `cma-es/`, `nevergrad/`, `ariel/`, `astropy/`, `pydantic/`, plus `index.md` and one `log.md`; layout rules in `.claude/SCHEMA.md`, commands `/ingest` and `/query` in `.claude/commands/`.

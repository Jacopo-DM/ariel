- `python tools/run_notebooks.py [FILE ...] [--slow] [--timeout S] [--save]`: runs the notebooks of `tests/functional` from a clean kernel and prints PASS, FAIL or SKIP for each (`tests/unit/test_tools/test_run_notebooks.py`); `python tools/run_examples.py [SCRIPT ...]`: runs each script of `examples/` as its own process in a temporary folder with the small arguments of its row in `EXAMPLES` (`Example`: `args`, `opengl`, `after`, `timeout`, built with `row()`; `MODULES` lists the files the scripts import), a producer before the scripts that read its files, and prints PASS, FAIL or SKIP for each (`tests/unit/test_tools/test_run_examples.py`); `python tools/render_floors.py`: renders one picture per world; `python tools/measure_overlap.py`: counts bodies with overlapping modules (`tests/unit/test_tools/test_measure_overlap.py`). `python tools/benchmark.py`: times the four workloads of the speed-up goal, each run in a fresh process (`tests/unit/test_tools/test_benchmark.py`).
